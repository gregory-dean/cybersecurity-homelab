# Troubleshooting Guide

## VM Cannot Communicate with Another VM

### Symptoms

• Ping requests fail  
• Remote connections fail  
• Services are unreachable  

### Checks

• Verify VirtualBox network adapter settings  
• Confirm systems are on the same subnet  
• Confirm firewall settings  
• Confirm IP addresses
