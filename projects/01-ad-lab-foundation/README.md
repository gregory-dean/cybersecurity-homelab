# Project 01 - Active Directory Lab Foundation

## Overview
This project establishes the core identity infrastructure for the homelab by deploying Active Directory and joining a Windows client system to the domain.

## Objectives
- Build a functioning Windows domain
- Create test users and groups
- Join a workstation to the domain
- Validate login and network communication
- Document the build process

## Systems Involved
- Windows Server
- Windows client
- VirtualBox networking

## Validation
- Domain created successfully
- Client joined to domain
- Test user can authenticate
- Systems can communicate as expected

## Skills Demonstrated
- Windows administration
- Active Directory setup
- Host networking
- Documentation
