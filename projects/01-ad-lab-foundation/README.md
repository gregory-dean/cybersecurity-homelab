## Project 01 - AD Lab Foundation

## Overview

This project will document the Identity and Access phase of the homelab build.

Planned work includes:

- Installing Active Directory Domain Services
- Promoting DC-01 to a domain controller
- Creating users and groups
- Joining WINCLIENT-01 to the domain
- Validating domain authentication
- Documenting basic Group Policy configuration

This project depends on the infrastructure completed in Project 00.
