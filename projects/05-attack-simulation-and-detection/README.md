# Project 05 – Attack Simulation and Detection

**Status:** Planned — not started.

## Overview

This project will document controlled attack simulation in the lab and the corresponding detection and investigation workflow.

## Objectives

- Perform Nmap reconnaissance
- Simulate failed login attempts
- Test suspicious PowerShell activity
- Simulate Linux sudo abuse
- Test service creation or scheduled task persistence
- Investigate resulting logs and alerts

## Lab Systems Used

- `KALI-01` – Attack simulation
- `SIEM-01` – Detection and investigation
- `DC-01`, `WINCLIENT-01`, `UBUNTU-01` – Targets
